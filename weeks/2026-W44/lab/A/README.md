## Build rules (lane A)
- Build exactly to the spec. Don't read `state/learnings.md`, lane-0 scripts or storyboards, or house-style refs; no white-canvas/iOS look.
- Kit (Remotion, remocn, audio engine, cutouts) is tools only. Fonts per spec: Barlow Condensed Bold, Source Sans 3 Semibold, IBM Plex Mono Medium.
- Voice: cast from the VO DIRECTION description in each spec, not from our usual casting.
- Hook 1 only (ChatGPT asked for 3 masters, not 9). Hooks 2–3 stay on file for a later test.
- Where the spec is silent, take the most literal reading and log it in `<id>-gaps.md`.

## Shared production rules (from ChatGPT)
- Canvas 1080×1920, 30 fps. Essential text in x=96–880, y=240–1430; subtitles y=1220–1410. Check platform overlays before export.
- FuelMyBuild as a plain text wordmark. One main visual, one headline, one supporting detail. Headlines 80–104 px, subtitles 48–56 px, UI fields ≥44 px.
- Mockups show only verified fields; fictional records marked DEMO BUILD. Generic comment bubbles sit outside the app mockups.
- Studio part photos may illustrate a demo log entry but must not pose as a real install photo.
- Intelligible VO first; instrumental music under it, cleared for all three platforms.
- Each table row is one second; a dash means no new speech; held text stays visible.
- Keep the story visual on screen during the follow CTA; sign-up goes in the caption.
- Sunday read for these: retention at 3/5/10 s, average watch time, substantive comments, follows.
