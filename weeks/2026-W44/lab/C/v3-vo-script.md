# Lab lane C v3: VO script (Wayne records)

Windows come from the scripts and are the same numbers the scene code and subtitles use (`v3film/src/timeline/<id>.json`, field `vo`). Word times in those files are estimates; after recording, export each line with its real word timings and we replace them, then re-time cuts and word reveals to the real takes.

How to record: one clean take per line (plus a safety), mono, 48 kHz, no music, about 0.5 s of room tone before and after. Name files `<id>-<n>-<speaker>.wav` (for example `C3-GAR-04-Okafor.wav`). A pause marked `| (0.2)` is the gap in seconds; *italics* mark the emphasis word. URLs are read "fuel my build dot com". If a line runs long, tell us: we cut words, we don't speed you up past 1.06x.

Lead hook for each reel is A (the first line below). Hooks B and C are in the script files if you want to record them for the hook test.
